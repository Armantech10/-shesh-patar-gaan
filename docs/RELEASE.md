## 📱 Release Notes & Distribution Details

This Android APK package is an internal preview and testing release generated via Expo Application Services (EAS Build). 

### Features Included in Build

1. **Retro Walkman Deck Interface**: Full analog mobile player deck with rotating reels, bias indicators, track timers, and mechanical button feedback.
2. **YouTube Audio Player**: Background audio player integration streaming curated Bengali nostalgia archives.
3. **Firebase Live Listener Presence**: Real-time integration with Firebase Realtime Database tracking active listeners across both web and mobile clients.
4. **Bengali Cultural Archives & Memories**: Bottom tab navigation to browse music archives and write handwritten memory scribbles.
